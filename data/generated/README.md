# Generated data

The full synthetic dataset generated by `scripts/generate_synthetic_data.py` is intentionally kept out of Git because it is large and reproducible.

Run from the repository root:

```bash
python scripts/generate_synthetic_data.py
```

The command creates the full outputs in this directory locally.

A small generated sample is committed as `sample_mobile_trajectories.csv` so the repository contains a directly viewable example of the generated output.
